# Interactive GPU particle beaker

Open `Assets/Scenes/ThreePhase3D/ParticleBeakerDrop.unity` and enter Play Mode. Use **Run** for inspection or **Measure drop + slosh** to reset the water and time a 0.4 s simulated release. Copy the `GPU drop:` line from Unity's Console. The test reports wall-clock frame rate and simulation throughput, then requests one asynchronous position snapshot if the device supports it.

The default 9 mL cube starts from rest 10 mm above the floor before spawn jitter. In Edit Mode, enable **Larger Beaker** under **Three Phase 3D Apparatus → Particle Beaker Drop → Release Settings** to use the 120 mm inner diameter, 160 mm deep beaker and a 250 mL cube. Both presets use the same release gap and nominal particle density. The larger case uses about 166,000 particles, so actual playback speed depends on GPU throughput. The benchmark prints the release volume. The GPU solver defaults to 0.4 ms substeps and uses a wall-clock accumulator. The scene caps rendering at 60 FPS and typically dispatches 41 or 42 substeps per frame at that rate with the default timestep and 100% playback. Catch-up after a stall is limited to 32 ms of simulated time. The scene restores the previous frame cap and VSync setting when disabled. The particle renderer consumes the solver's position and velocity buffers directly. The standard test performs no per-frame CPU readback. The snapshot reports particle count, nonfinite positions, particles outside the cavity below the rim, lowest vertical position and radial extent. A particle below the rim and outside the cavity may be a real escape over the open rim, so the snapshot count requires visual context.

Before entering Play Mode, select **Three Phase 3D Apparatus** in the Hierarchy. Under **Particle Beaker Drop → Simulation Settings** in the Inspector, set the solver timestep, playback percentage, gravity, pressure, near pressure, viscosity strength and wall bounce. Save the scene to keep those values.

The **Simulation Controls** panel appears in the Game view. Use **Solver step** to select a fixed timestep between 0.1 and 1 ms and **Step once** to advance exactly one step while paused. **Playback speed** starts at 25%. Set it to 100% to target real-time playback. Gravity, pressure, near pressure, viscosity strength and wall bounce take effect on the next solver step. **Reset** restores the initial particle positions and velocities. **Restore scene settings** reapplies the Inspector values. Changes made in the Game view apply to the current run. Settings are locked during a benchmark, which always covers 0.4 simulated seconds. The measured drop should still exceed the original 30 FPS minimum. This is separate from simulation throughput. Inspect the fall, floor impact and outward spread in the Game view. The snapshot and frame timing do not establish agreement with a physical experiment.

This scene uses a cylindrical inner collision boundary and a separate exterior box. It is an interactive liquid test with provisional SPH parameters and collision damping. It does not yet model glass exterior contact, heat transfer, ice, vapour, or phase change. The earlier cut-cell scenes remain available for their existing tests.
